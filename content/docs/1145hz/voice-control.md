Voice-led search and playback is the main idea behind 1145Hz Player. It is planned, not available.

## Platform differences

Voice features may not be offered on every platform. Each release will state where voice control is implemented. If a platform is not listed, assume voice control does not work there.

## Microphone setup

Voice control will need microphone access. This guide will explain how to grant and revoke that permission on each supported operating system once those systems are confirmed.

## Voice commands

The list of supported commands will be published with the first release that includes voice control.
